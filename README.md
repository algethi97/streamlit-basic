# Streamlit Basic

Streamlit의 기본 위젯 학습 및 OpenAI 최신 모델(GPT 5.5+)을 연동한 감성적인 오션 테마 멀티세션 챗봇 프로젝트입니다.

---

## 🚀 주요 기능

### 1. 감성적인 오션 테마 & 비주얼 연출 (`modules/theme.py`)
- **☀️ 해수면 ↔ 🌌 심해 어비스 테마**:
  - **해수면 모드**: 햇살이 투과하는 맑고 청량한 에메랄드 블루 수면 뷰
  - **심해 어비스 모드**: 칠흑의 어둠과 네온 시안(Cyan) 형광 발광이 어우러진 신비로운 심해 뷰
- **사이드바 원클릭 테마 전환**: 사이드바 상단 버튼으로 화면 전체(배경, 글자색, 사이드바, 말풍선, 하단 입력창)가 일체형으로 즉시 전환
- **입체적인 20개 S자 곡선 상승 기포 (Bubbles)**:
  - 다양한 크기(7px~38px)의 기포가 물결을 타고 좌우로 살랑거리며 솟구치는 유려한 애니메이션
  - 음수 딜레이(Negative Delay)를 적용하여 화면 전환 즉시 화면 전역에서 자연스럽게 유영
- **글래스모피즘(Glassmorphism) UI**: 사이드바, 채팅 말풍선, 하단 입력창에 반투명 유리 질감 및 네온 테두리 적용
- **하단 바 완전 투명화**: Streamlit 기본 하단 입력창(`stBottom`)의 답답한 직사각형 박스를 완벽히 투명화하여 바닥 끝까지 끊김 없는 배경 연결

### 2. OpenAI 챗봇 & 세션 메모리 보안 (`app2.py`, `modules/api_key.py`)
- **최신 OpenAI 모델 지원**: `gpt-5.6-luna` (기본 모델), `gpt-5.6-terra`, `gpt-5.6-sol`, `gpt-5.5` 선택 가능
- **API 키 세션 메모리 격리**:
  - 입력된 OpenAI API 키는 브라우저 세션 메모리(`st.session_state`)에만 임시 보관
  - 데이터베이스나 파일, 깃 리포지터리 어디에도 저장되지 않아 깃허브 공개 시에도 완벽한 보안 유지
- **스트리밍 타이핑 답변**: `st.write_stream`을 통한 실시간 고속 스트리밍 응답
- **간이 닉네임 접속 시스템 (`modules/auth.py`)**: 비밀번호 평문 저장의 보안 취약점을 완전히 제거하고 닉네임 기반으로 안전하게 접속

### 3. 세션 및 대화방 관리 (`modules/database.py`)
- **SQLite 기반 로컬 영속화**: `chat_history.db`를 통해 유저별 대화방 및 메시지 이력 추적
- **유저당 최대 10개 세션 제한**: 11번째 세션 생성 시 가장 오래된 세션이 자동으로 정리되는 FIFO 큐 방식 적용
- **세션당 최대 100회 대화 한도**: 대화방별 실시간 턴 카운트 및 프로그레스 바 표시, 100회 도달 시 입력 자동 잠금
- **대화방 제목 자동 생성**: 첫 질문의 앞 20자를 기반으로 대화방 타이틀 자동 명명 및 개별 삭제 기능

### 4. 체계적인 사이드바 UI 레이아웃
위에서부터 아래로 직관적인 순서로 일목요연하게 배치:
1. **🌊 해양 테마 제어** (해수면 / 심해 어비스 버튼)
2. **👤 닉네임 접속 상태**
3. **🔑 OpenAI API 키 등록/관리 블럭**
4. **🚪 접속 종료 버튼**
5. **💬 OpenAI 채팅 링크** (`st.page_link`)
6. **📜 과거 채팅 내역 링크** (`st.page_link`)
7. **⚙️ 모델 선택 & 대화 횟수 프로그레스**
8. **📁 대화방 관리 블럭** (보유 세션 수, 새 대화 생성, 대화 목록, 삭제)

## 🛠️ 시작 가이드

### 1. 패키지 설치
`uv` 패키지 관리자를 사용하여 가상환경 및 의존성을 설치합니다:
```bash
uv sync
```

### 2. 실행 방법
Windows 배치 파일을 실행하거나 uv 명령어로 실행할 수 있습니다:
```bash
# 배치 파일 실행
run.bat

# 또는 uv 명령어로 직접 실행
uv run streamlit run app2.py
```

## 📁 프로젝트 구조

```plaintext
streamlit-basic/
├── app.py              # Streamlit 기본 위젯 학습 예제
├── app2.py             # OpenAI 챗봇 메인 엔트리포인트 (사이드바 및 네비게이션)
├── chat_history.db     # SQLite 데이터베이스 (Git 추적 대상)
├── modules/            # 비즈니스 로직 분리 모듈
│   ├── database.py     # SQLite DB 관리 (users, sessions, messages)
│   ├── auth.py         # 닉네임 기반 안전 접속 시스템
│   ├── api_key.py      # OpenAI API 키 세션 격리 팝업 및 상태 관리
│   ├── app2_history.py # 과거 채팅 내역 조회 페이지 (/history)
│   └── theme.py        # 해양 테마(해수면/심해) CSS 및 20개 기포 애니메이션
├── widgets/            # 컴포넌트별 Streamlit 위젯 예제 모듈
├── pyproject.toml      # uv 프로젝트 설정 및 의존성 명세
├── run.bat             # 앱 원클릭 실행 스크립트
└── README.md           # 프로젝트 종합 문서
```
